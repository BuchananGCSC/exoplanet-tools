# Classroom Computer System Purchase Proposal

**Prepared for:** Department Head and Principal  
**Prepared by:** Jeremy Buchanan  
**Purpose:** Approval to purchase six compact classroom computer systems for student astronomy, physics, and STEM software work.

## Executive Summary

I recommend purchasing **six KAMRUI AM21 mini PCs**, configured with the AMD Ryzen 7 8745HS processor, AMD Radeon 780M integrated graphics, **32 GB DDR5 memory**, **1 TB NVMe solid-state storage**, and Windows 11 Pro. My preferred supplier is the **KAMRUI official store**, with the Amazon listing as a practical alternate source if district purchasing procedures, availability, or payment requirements make it preferable.

These systems are intended primarily for students to create and edit WorldWide Telescope (WWT) tours for use in the planetarium. They will also provide capable workstations for physics and astronomy activities, Python/Jupyter computing, GMAT orbital analysis, 3-D-printing slicers, CAD/modeling, data analysis, and general student productivity. The recommended configuration prioritizes graphics capability, sufficient memory, solid-state storage, compact deployment, and useful display connectivity rather than merely meeting basic office-computing needs.

## Instructional Need

The department needs reliable student workstations that can support graphics- and data-intensive instructional work, not only web browsing and word processing. Key intended uses include:

- WorldWide Telescope tour development and presentation preparation for the planetarium
- Astronomy visualization, image work, and spatial/3-D learning activities
- Python, Jupyter notebooks, scientific data analysis, and computational modeling
- GMAT and other orbital or spacecraft-mission analysis software
- CAD/modeling and 3-D-printing slicer software
- Physics laboratory data processing, graphing, spreadsheets, and student project work
- Standard instructional activities, including browser-based work, documents, presentations, and video conferencing

Six matching systems will permit a small student design/production group to work simultaneously, simplify imaging and support, and provide a consistent platform for classroom software and accessories.

### Why this configuration

The Ryzen 7 8745HS and Radeon 780M pairing is materially stronger than low-cost, office-oriented mini PCs that use older Ryzen 5 processors or entry-level integrated graphics. It provides a practical balance: enough graphics and processor performance for WWT and STEM visualization without the extra expense, heat, noise, and physical size of a separate gaming/workstation tower with a discrete graphics card.

The 32 GB / 1 TB configuration is deliberate. A 16 GB / 512 GB system may run basic applications, but it leaves much less margin for graphically demanding applications, browser tabs, local astronomy assets, data files, CAD/slicer projects, and the expected multi-year service life of school equipment. Specifying the configuration up front avoids an immediate upgrade project and helps make the system durable as instructional needs expand.

## Deployment and Acceptance

Before classroom deployment, the systems should be checked against the purchase specification and prepared as a uniform set.

1. Verify the delivered CPU, installed memory, SSD capacity, Windows edition/activation, display outputs, and network connectivity.
2. Record serial numbers and asset tags; retain invoices, warranty details, and configuration screenshots.
3. Apply current firmware, Windows, graphics, and security updates.
4. Install and test WorldWide Telescope, required planetarium workflow software, Python/Jupyter tools, GMAT, CAD/slicer applications, office/browser tools, and district-required security or management software.
5. Test each unit with the intended monitor/projector/planetarium preparation display, network connection, keyboard/mouse, and any required adapters.
6. Create a standard software image or setup checklist so all six systems remain consistent over time.
